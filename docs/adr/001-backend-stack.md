# ADR 001: Backend Tech Stack

## สถานะ (Status)
ได้รับการอนุมัติ (Approved)

## บริบท (Context)
หน้ากาก (Frontend) ของระบบ StockManagement-KI มีแต่ข้อมูลปลอม (Mock Data) เราต้องการสร้างหลังบ้าน (Backend) เพื่อให้ระบบทำงานได้จริงและมีความน่าเชื่อถือ

## การตัดสินใจ (Decision)
เราจะใช้เทคโนโลยีดังต่อไปนี้ในการสร้างหลังบ้าน:
- **Framework:** NestJS (เพื่อโครงสร้างที่แข็งแรงและมีระเบียบ)
- **Database:** PostgreSQL (เพื่อเก็บข้อมูลที่มีความสัมพันธ์กันอย่างถูกต้อง เช่น สต๊อกสินค้า)

## ผลที่ตามมา (Consequences)
- ทีมต้องมีความรู้ใน TypeScript, NestJS และ SQL
- โครงสร้างโปรเจคจะมีความชัดเจนและขยายต่อได้ง่าย
